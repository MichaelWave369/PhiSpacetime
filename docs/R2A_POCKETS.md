# R2a: conforming recursive pocket discretization

Compare uniform square leaves, quadtree leaves and nine-way (3x3) leaves on the same static forced scalar PDE -laplacian(u)=f with homogeneous Dirichlet data on the unit square. This is the static stiffness problem associated with the scalar wave operator, not a dynamic wave comparison. Each leaf is a bounded pocket. All edge breakpoints from adjacent leaves are shared, and each leaf is triangulated as a center fan. This yields conforming P1 finite elements without hanging-node interpolation. Exact integer lattice coordinates avoid floating-point topology mismatches. The mesh is not balanced; triangle aspect ratios can degrade at steep level transitions.

The analytic cases are sin(pi x)sin(pi y) and the same field plus a compact separable polynomial bump at (.36,.61). The exact Laplacian is computed analytically. Uniform refinement is breadth-first; adaptive selection uses h^2 times maximum sampled absolute source at nine interior points. This is a deterministic source-informed heuristic, not a proven a posteriori error estimator. It has access to the same source in both adaptive methods. The hierarchy depth cap is five for both arities, producing different maximum possible cell sizes; report realized counts and depth. Leaf budgets are caps, not equal DOF or equal runtime. Each triangle uses a shared P1 stiffness and three-point load quadrature, Jacobi-preconditioned CG with relative residual threshold 1e-9, and independent 16-point Duffy integration of relative L2 field error.

Test partition area, exact integer topology and edge incidence, matrix symmetry, linear patch consistency at interior nodes, analytic source, uniform convergence, and adaptive improvement for each arity. No comparative winner is a gate. Sweep budgets 16,64,256,1024, both cases, three methods. Report leaves, free DOFs, triangles, matrix entries, iterations and error. No wall-clock or memory superiority claim; Python assembly is a reference implementation, not optimized. Realized DOFs and mesh quality must be matched for subsequent efficiency claims.

Run python -m phispacetime.pocket_benchmark. R2b should add residual-based refinement, explicit shape-quality and resource accounting, same-error comparisons and a held-out field; R2c should address dynamic wave evolution and interfaces. This is a standalone nine-way candidate inspired by NBG Pocket Mesh, not an integration of its repository or PhiMycelium. Existing R1g absorber remains approximate.
